# Diagramas para o TCC

Esta pasta separa os diagramas por tipo, seguindo a organizacao solicitada para o documento.

## Pastas

- `caso-de-uso/`: caso de uso fiel as telas e acoes atuais do aplicativo.
- `diagrama-atividade/`: atividades principais existentes na aplicacao.
- `diagrama-classes/`: estrutura de classes, telas, servicos e entidades usada pelo app.
- `modelagem-conceitual/`: modelagem conceitual atualizada conforme o banco Supabase.
- `modelagem-logica/`: modelagem logica atualizada conforme as tabelas reais.
- `dicionario-dados/`: dicionario das tabelas, colunas, chaves e finalidade.
- `arquitetura/`: arquitetura geral do sistema.
- `fluxo-supabase/`: fluxo de atualizacao de GPS entre app, Supabase e dispositivo/simulador.

## Observacao

Os arquivos estao em SVG para manter texto e linhas nitidos no Word. O dicionario de dados principal esta em Markdown para facilitar copia e edicao no documento.
