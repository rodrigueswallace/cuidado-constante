# Caso de uso

Diagramas criados com base nas telas e funcionalidades reais do app:

- `caso_de_uso_tutor_app.svg`: acoes realizadas pelo tutor no aplicativo.
- `caso_de_uso_dispositivo_supabase.svg`: acoes do dispositivo/simulador e validacoes pelo Supabase.

Os casos foram separados para evitar um unico diagrama muito carregado e facilitar a insercao no TCC.
